# Bloomy

Игровое веб-приложение для заботы о себе: выполняешь задания — растёт цветок.

Без сборки: чистые HTML, CSS и JS-модули. Данные хранятся в браузере: всё основное — в localStorage, файлы анализов — в IndexedDB. Резервную копию можно скачать в разделе «Ещё».

## Что внутри

- **Сегодня** — напоминания, цветок месяца, батарейка энергии, подсказка по дню цикла, план дня (по энергии и фазе цикла), карточки заданий (одну в день можно заменить), слова поддержки вечером.
- **Вода** — трекер воды с нормой и графиком за неделю.
- **Полка** — награды текущего месяца с прогрессом и цветы прошлых месяцев. В начале нового месяца показываются итоги.
- **Ещё** — цикл, отдых (дыхание, таймер паузы, идеи), замеры (таблица и график), здоровье (напоминания о врачах и хранение анализов), резервная копия.

Напоминания показываются при открытии приложения: веб-приложение без сервера не может присылать push-уведомления. Приложение можно установить на телефон («На экран Домой») и открывать офлайн.

## Локальный запуск

```
python3 -m http.server 8000
```

Открыть http://localhost:8000

## Деплой

Netlify: подключить репозиторий, Build command пустая, Publish directory — `.` (уже задано в `netlify.toml`).
