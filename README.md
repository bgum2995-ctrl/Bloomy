# Bloomy

Игровое веб-приложение для заботы о себе: выполняешь задания — растёт цветок.

Без сборки: чистые HTML, CSS и JS-модули. Данные хранятся в браузере (localStorage).

## Локальный запуск

```
python3 -m http.server 8000
```

Открыть http://localhost:8000

## Деплой

Netlify: подключить репозиторий, Build command пустая, Publish directory — `.` (уже задано в `netlify.toml`).
